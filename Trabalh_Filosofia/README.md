# Resistência — Memória, Cultura e Liberdade

Projeto desenvolvido como material educativo e exposição digital sobre o 4º eixo temático (Resistência) do Brasil Império. 
O site foi construído seguindo rigorosos padrões de web design editorial, acessibilidade e precisão histórica.

## Estrutura do Projeto

- `index.html`: Marcação semântica principal.
- `style.css`: Estilos, tipografia, layout responsivo e paleta de cores.
- `script.js`: Interatividade (menu mobile, animações de scroll, barra de progresso).
- `img/`: Imagens do site (veja `img/LEIA-ME.txt`).
- `README.md`: Documentação.

## Tecnologias Utilizadas

- HTML5 (Semântico e Acessível)
- CSS3 (Flexbox, CSS Grid, Variáveis)
- JavaScript Vanilla (Sem dependências externas)
- Fontes: Google Fonts (Playfair Display e Inter)

## Como Executar

1. Descompacte o arquivo zip.
2. Abra o arquivo `index.html` em qualquer navegador web moderno (Chrome, Firefox, Safari, Edge).
3. Não é necessário servidor local, mas extensões como "Live Server" (VSCode) são recomendadas caso deseje editar o código.

## Notas sobre Design e Conteúdo

- **Acessibilidade**: O projeto respeita preferências de movimento reduzido (`prefers-reduced-motion`), possui contraste adequado e utiliza tags semânticas.
- **Imagens**: coloque os arquivos na pasta `img/` com os nomes listados em `img/LEIA-ME.txt`. Enquanto uma imagem não existir, o site mostra automaticamente o fundo em CSS no lugar (nada quebra). Preencha os campos `[autor, ano, fonte]` das legendas e a seção "Créditos das imagens" no `index.html`.
- **Responsividade**: Layout testado para funcionar desde telas de smartphones (320px) até monitores ultrawide.
